# College-Faculty-and-research-details

A comprehensive **Faculty & Research Directory Portal** for Chanakya University, built as a multi-page static web application.

## Live Site
Hosted on Netlify — see deployment URL after push.

## Features
- **Faculty Directory Dashboard** — 154 faculty & researcher profiles with interactive charts
- **Individual Profile Pages** — Full bio, qualifications, publications, projects, achievements & international experience
- **Research Projects Portal** — 119 funded projects with grant details and investigator links
- **Publications Dashboard** — 440+ scholarly publications with domain classification and search
- **International Collaborations Tracker** — 42 verified international track profiles
- **Interactive Chart.js Visualisations** — Click bars/slices to filter the directory


## Pages
| Page | Description |
|------|-------------|
| index.html | Faculty & Researcher Directory Dashboard |
| profile.html | Individual Faculty Profile Page |

## Tech Stack
- HTML5, CSS3 (Vanilla), JavaScript (ES6+)
- Chart.js for interactive visualisations
- Font Awesome icons
- Google Fonts (Inter)

## Data
